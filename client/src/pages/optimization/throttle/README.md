# 1. 쓰로틀이란?

- 쓰로틀은 짧은 시간 간격으로 연속해서 발생하는 이벤트를 그룹화하여 과도한 이벤트 핸들러 호출을 방지하는 프로그래밍 기법으로, 지정된 시간 간격 내에서는 이벤트 핸들러가 최대 한 번만 호출되도록 동작한다.

- 쓰로틀은 이벤트가 빠르게 반복적으로 발생하더라도 일정 간격으로만 이벤트 핸들러가 실행되므로, 과도한 계산이나 네트워크 요청을 방지할 수 있다. 예를 들어, 버튼 클릭 시 비용이 많이 드는 계산이 실행되는 것을 방지하기 위해 사용될 수 있다.

# 2. useThrottle 훅

- 이 커스텀 훅은 이벤트가 연속적으로 발생하더라도 지정된 시간 간격(delay) 내에서는 최대 한 번만 콜백 함수가 호출되도록 한다. 즉, 이벤트가 트리거될 때마다 일정 시간 간격으로만 콜백 함수가 실행되도록 제한한다.

## 1. 사용법

1. `useThrottle` 훅을 호출하여 초기화한다.
2. 반환된 함수를 사용하여 지연 시간(delay)과 이 지연 시간 내에 실행될 콜백 함수(callback)를 지정한다.

   ```javascript
   const throttle = useThrottle(); // 1
   throttle(callback, delay); // 2
   ```

## 2. 실행 흐름

### 1. 최초 쓰로틀 트리거

- `useThrottle` 훅을 처음 실행할 때, `timerId`는 `null`로 초기화된다. 이 상태에서 쓰로틀이 처음으로 트리거되면 `timerId.current`가 `null`이므로 `return` 문을 건너뛰고 `setTimeout`을 사용하여 `delay` 시간이 경과한 후에 콜백을 실행하도록 설정한다.

### 2. 쓰로틀이 다시 트리거될 때

- 쓰로틀이 트리거된 후, `timerId.current`가 존재하면 (즉, 타이머가 이미 실행 중이면) `return` 문이 실행되어 콜백이 호출되지 않는다. 이는 `delay`가 경과하기 전에 다른 이벤트가 트리거되는 것을 방지하기 위함이다.

### 3. 설정된 지연 시간 후 콜백 실행

- 쓰로틀이 트리거된 후, `delay` 시간이 지나면, `setTimeout`에 의해 지정된 `callback`을 실행하고 `timerId.current`를 `null`로 초기화하여 이후 이벤트를 받을 준비를 한다. 이후 새로운 이벤트가 발생할 때마다 같은 과정이 반복되며, `delay` 시간이 경과할 때마다 콜백 함수가 실행된다. `delay` 시간 내에 반복적인 이벤트가 발생하더라도, 그 시간 동안은 콜백이 한 번만 호출된다.
